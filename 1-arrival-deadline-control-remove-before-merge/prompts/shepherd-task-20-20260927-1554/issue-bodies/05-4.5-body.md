- `./mvnw clean package -Popenliberty` succeeds on JDK 17 and all test sources compile.
- The full browser flow above passes, including update persistence, reopen initialization, and cancel behavior.
- Home and relevant direct HTTP requests return HTTP 200.
- Destination editing and routing selection remain functional.
- Runtime logs contain none of: `<f:metadata> Parent UIComponent`, `TagException`, `VerifyError`, `FacesException`, `CWWKZ0002E`, `CWWKZ0003E`, recurring batch authorization failures, or new feature-attributable FFDC files.
